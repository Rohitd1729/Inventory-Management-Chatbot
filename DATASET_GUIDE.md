# 📊 Using Real External Datasets

This guide explains how to use **real-world datasets from external sources** instead of AI-generated data.

---

## 🎯 Why Use External Datasets?

For this internship POC, you want to demonstrate working with **real data from actual sources**:
- ✅ Shows ability to work with existing data formats
- ✅ Demonstrates data transformation skills
- ✅ More realistic for business scenarios
- ✅ Follows best practices (not synthetic data)

---

## 📥 Recommended Dataset: Maven Toys

**Best choice for this project** — Real retail inventory data from a toy store chain.

### Download Instructions

1. **Go to Kaggle**  
   https://www.kaggle.com/datasets/mysarahmadbhat/toy-sales

2. **Create Free Account**  
   Click "Sign Up" if you don't have a Kaggle account (it's free)

3. **Download Dataset**  
   Click the "Download" button (you may need to accept terms)

4. **Extract Files**  
   Unzip the downloaded file to your project directory  
   You'll get: `products.csv`, `stores.csv`, `inventory.csv`, `sales.csv`

5. **Convert Format**  
   Run the converter:
   ```bash
   python convert_maven_toys.py
   ```

6. **Done!**  
   You now have `inventory.csv` with 1,500+ real records

---

## 🔄 What the Converter Does

The `convert_maven_toys.py` script:

1. **Loads 3 CSV files** from Maven Toys dataset
2. **Merges** product, store, and inventory data
3. **Renames columns** to match our schema
4. **Calculates** minimum stock levels (30% of current stock)
5. **Generates** last movement dates (realistic distribution)
6. **Outputs** clean `inventory.csv` ready to use

**Result**: 1,500+ inventory records from a real toy retail chain!

## 📝 Required CSV Format

Your final `inventory.csv` must have these columns:

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| `product_id` | string | Unique identifier | "P001" |
| `product_name` | string | Product name | "LEGO Classic Set" |
| `category` | string | Product category | "Toys" |
| `current_stock` | integer | Current quantity | 45 |
| `min_stock_level` | integer | Reorder threshold | 20 |
| `last_movement_date` | date | Last in/out date | "2025-02-10" |
| `warehouse_name` | string | Storage location | "Warehouse A" |
